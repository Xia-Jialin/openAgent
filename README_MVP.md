# OpenAgent Frontend Development Studio - MVP

这是一个最小化可行产品（MVP），将通用AI助手转换为专门的前端开发智能体。

## 功能特性

### 1. React开发工具
- **create_react_component**: 根据描述创建React组件
- **create_react_project**: 创建基于Vite的React项目
- **install_package**: 安装npm包到项目

### 2. 代码编辑器
- 集成CodeMirror编辑器，支持JSX语法高亮
- 实时代码编辑和保存
- 文件树管理
- 代码自动缩进和括号匹配

### 3. 实时预览
- HTML文件实时预览
- React组件预览提示
- 自动刷新预览

### 4. 会话管理
- 多会话支持
- 会话历史记录
- 工作空间隔离

## 快速开始

### 1. 启动应用
```bash
go run main.go
```

### 2. 访问界面
打开浏览器访问 http://localhost:8081

### 3. 创建第一个React项目
在聊天框中输入：
```
创建一个React项目，名为my-app
```

### 4. 创建React组件
在聊天框中输入：
```
创建一个名为Header的React组件，它包含导航栏和logo
```

### 5. 安装包
在聊天框中输入：
```
安装tailwindcss包
```

## 使用示例

### 示例1：创建完整的React应用
```
1. 创建React项目my-portfolio
2. 创建Header组件，包含导航菜单
3. 创建Hero组件，包含标题和介绍
4. 创建Footer组件
5. 安装tailwindcss
```

### 示例2：编辑代码
1. 点击左侧文件树中的文件
2. 在代码编辑器中修改代码
3. 点击Save按钮保存
4. 查看实时预览

## 界面说明

### 左侧边栏
- **Workspace**: 显示当前会话的文件
- **Sessions**: 会话列表

### 主要区域
- **代码编辑器**: 支持JSX语法高亮
- **预览面板**: 实时预览HTML文件
- **聊天区域**: 与AI助手交互

### 底部
- **输入框**: 输入命令或描述
- **发送按钮**: 发送消息
- **新会话按钮**: 开始新会话

## 注意事项

- 这是一个MVP版本，功能有限但足够验证概念
- 需要配置`.env`文件中的API密钥
- 每个会话都有独立的工作空间
- 建议在开发环境中使用

## 故障排除

### 端口占用
如果8081端口被占用，可以修改`main.go`中的端口号。

### MCP服务器问题
如果MCP服务器启动失败，检查`mcp.json`配置。

### 文件路径问题
确保文件操作在会话工作空间内进行。
